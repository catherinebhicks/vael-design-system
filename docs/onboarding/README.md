# Onboarding — start here

**Last updated: 2026-07-17.**

Practical, non-developer-friendly guides for picking up the Vael Design System —
whether you're using the components in code, the design file in Figma, or feeding it
to an AI agent.

| Guide | What it covers |
|-------|----------------|
| **[Installing & using Storybook](using-storybook.md)** | Run the live component catalog on your machine (or just view the published one online), and *why* a non-dev would want to. For someone comfortable with a terminal but not a full-time dev. |
| **[Importing into Figma](import-into-figma.md)** | Load the `.fig` archive into Figma (web + desktop), install the fonts, and publish it as a team library. |
| **[Designing with an LLM](designing-with-an-llm.md)** | Connect Figma to an AI via **MCP**, then use it three ways: feed the system in as context, *design* new screens on Vael's components, and push Figma changes back into the design-system code. |

For the story and reasoning behind the system (history, downstream usage,
governance), see the [docs home](../README.md). For the editable Figma archives
themselves and how to export a new snapshot, see [`figma/`](../../figma/).
