# Footer

The site footer band: a brand mark and description, columns of navigation links, and a bottom bar with copyright and legal/utility links. A thin, themed composition — pass real links so it stays navigable and accessible.

## Props

Import from `vael-design-system`.

| Prop | Type / Values | Default | Notes |
| --- | --- | --- | --- |
| `brand` | `React.ReactNode` | — | Brand mark or name shown top-left. |
| `description` | `React.ReactNode` | — | Short supporting line under the brand. |
| `columns` | `FooterColumn[]` | `[]` | Link columns — usually 2–4. Each is `{ heading, links: { label, href }[] }`. |
| `copyright` | `React.ReactNode` | — | Bottom-bar left content, usually a copyright line. |
| `legal` | `React.ReactNode` | — | Bottom-bar right content, usually legal/utility links. |
| `variant` | `'ink' \| 'subtle'` | `'ink'` | `ink` is a dark band; `subtle` a bordered light surface. |
| `sx` | `SxProps<Theme>` | — | Style overrides. |

Link and heading contrast auto-adjust for the dark `ink` variant.

## When to use

- Close a marketing or portfolio page with global navigation, contact, and legal links.
- Keep to 2–4 link columns with short, parallel headings so the grid stays scannable.
- Use `ink` to anchor the bottom of a page; use `subtle` inside an app shell where a full dark band would be heavy.
- **Don't** duplicate the primary nav wholesale — the footer is for secondary and utility links, not a second `AppBar`.

## Accessibility

- Each column renders inside a `<nav>` landmark and the root is a `<footer>` landmark, so assistive tech can find and skip it.
- Pass real `href`s — footer links must be keyboard-reachable and describe their destination (avoid bare "here").
- The `ink` variant sets light link text on a dark band; keep any custom colors WCAG-compliant, and don't rely on color alone to signal a link (hover raises contrast, not just hue).
