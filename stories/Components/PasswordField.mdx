# PasswordField

A controlled text input for password entry with a built-in show/hide toggle and an optional strength meter. Use it anywhere a user creates or enters a password — sign-up, sign-in, and change-password flows.

## Guidelines

### Do

- Enable `showStrength` on password *creation* flows (sign-up, reset) to guide users toward stronger passwords.
- Set `autoComplete="new-password"` when creating a password and `autoComplete="current-password"` when signing in.
- Pass `error` and a clear `helperText` together when validation fails.
- Keep the field controlled — always supply both `value` and `onChange`.

### Don't

- Show the strength meter on a sign-in field where the user is entering an existing password — it adds noise.
- Rely on the strength score as a security control — it is a lightweight client-side hint, not a policy check.
- Use a plain `TextField` for passwords — you lose the visibility toggle and accessible show/hide labels.
- Leave `label` empty; the field always needs a visible label.

## Props

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| value | string | — | Current password value (controlled). Required. |
| onChange | (event: ChangeEvent&lt;HTMLInputElement&gt;) => void | — | Change handler receiving the standard input event. Required. |
| label | string | 'Password' | Visible field label. |
| showStrength | boolean | false | Renders a strength meter and label below the field. |
| fullWidth | boolean | — | Expands the field to fill its container width. |
| size | 'small' \| 'medium' | — | MUI TextField size. |
| error | boolean | — | Applies the error state styling. |
| helperText | string | — | Helper text shown beneath the field; pair with `error` on validation failure. |
| autoComplete | string | — | Autocomplete hint, e.g. `'new-password'` or `'current-password'`. |

## Accessibility

- The visibility toggle is a real `IconButton` with an `aria-label` that switches between "Show password" and "Hide password" as state changes, so screen readers announce the current action.
- The strength meter exposes `aria-label="Password strength"` on the progress bar; the text label ("Weak", "Fair", "Good", "Strong") conveys the same information without relying on color alone.
- The field is keyboard reachable, and the toggle is in the tab order — users can reveal or hide the value without a mouse.
- Toggling visibility never clears or reformats the entered value, preserving the user's input across state changes.
