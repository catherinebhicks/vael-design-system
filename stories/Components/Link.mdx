# Link

A styled anchor for navigating within or away from the app. A thin re-export of MUI `Link` with the Vael theme applied.

## Props

Import `Link` from `vael-design-system`.

| Prop | Type / Values | Default | Notes |
| --- | --- | --- | --- |
| `href` | `string` | — | Destination URL |
| `underline` | `'none' \| 'hover' \| 'always'` | `'always'` | Underline behavior |
| `color` | `string` | `'primary'` | Theme color token |
| `variant` | Typography variant | `'inherit'` | Match surrounding text |
| `component` | `ElementType` | `'a'` | Swap in a router link (e.g. React Router) |

## When to use

- Use for navigation — moving to another page, view, or external resource.
- Set `component` to integrate with a client-side router while keeping styling.
- **Don't** use it to trigger an action on the current page — use a `Button` (`variant='text'`) so semantics and keyboard behavior are correct.

## Accessibility

- Link text should describe the destination; avoid bare 'click here'.
- For external links opened in a new tab, add `rel='noopener'` and signal the new-tab behavior.
- Ensure links are distinguishable from body text by more than color alone (the default underline handles this).
