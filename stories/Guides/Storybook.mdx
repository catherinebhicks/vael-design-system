# Storybook

Storybook is where design and engineering meet for review. Every Vael component has a Storybook page that mirrors the docs page structure.

## Story files

- `Component.stories.tsx` — default plus one story per variant.
- `Component.mdx` — docs tab narrative with live examples.

There are no separate `Component.test.tsx` unit-test files — the stories *are* the tests. Accessibility (axe) and visual-regression (Chromatic) checks run against the stories themselves; see the [Testing](?path=/docs/guides-testing--docs) guide.

## Docs tab structure

Match the docs page: Overview → Anatomy → Variants → Do/Don't → Accessibility → API. Engineers and designers both land here; neither should have to scroll past content meant for the other.
