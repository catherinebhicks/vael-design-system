# Performance

Guidelines for keeping the app fast: list virtualization, code splitting, and font loading.

## DataGrid / AG Grid virtualization

Virtualization is on by default. Don't disable it. Avoid `domLayout="autoHeight"` for tables over 50 rows — it defeats row virtualization.

## Code splitting

- Dialogs and Drawers — lazy-load with `next/dynamic`; their deps often dwarf the host page.
- Charts — `HighchartsClient` is already dynamic; don't re-wrap it.
- Flow Editor (`FlowCanvas`) — always dynamic; React Flow adds ~200 KB.

## Fonts

- Restrict IBM Plex to the weights the system uses — IBM Plex Sans 400/500/600/700, IBM Plex Mono 400/500/600.
- Prefer self-hosting via `@fontsource/ibm-plex-sans` + `@fontsource/ibm-plex-mono` (used in Storybook) so there's no external request; avoid `@import url(…)` in CSS — it blocks render.
