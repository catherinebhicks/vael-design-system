# Changelog

Version history for the Vael Design System. V0 establishes the baseline — token system, component library, and pattern documentation. Vael was **extracted from Fermie**, a data-dense bioprocess-monitoring product (since shelved); entries below trace how the extracted, portfolio-facing system evolved from that origin.

## V0 — Baseline · April 2026

Status: In progress. Light + dark mode shipped; **Blueprint / Engine-Room** visual identity; ~100 components documented in Storybook.

Establishes the baseline token system, component library, and pattern documentation. The roster and tokens were derived from the V0 Figma file and the Fermie product UI, then genericized (server-metrics vocabulary, no product names).

### Update · July 2026 — Blueprint reskin

The visual identity moved to **Blueprint / Engine-Room** to match the Vael case-study landing page: **IBM Plex Mono** for headings + labels/data (replacing Inter/DM Mono), blueprint-grid surfaces, hairline borders, tightened geometry (8px buttons/inputs, 14px cards), a blue focus glow, and mono metadata labels. Charts adopt IBM Plex Mono. A single toolbar toggle flips the Storybook chrome, components, and docs together. Brand blue `#1976d2` is unchanged. The landing page is the reference for this identity; the design system was shifted to match it.

### Update · July 2026 — Single-typeface (Mono) system

The initial reskin kept IBM Plex Sans for body + buttons. That split read as inconsistent against the mono UI, so **every variant folded into IBM Plex Mono** — the system is now a single-typeface (Mono) family, with weight carrying role (headings 600, prose 400, buttons 600). IBM Plex Sans is no longer used by the theme.

### Update · July 2026 — Responsiveness + viewport toggle

Components were made **mobile-safe down to `xs`** (previously desktop-first with no mobile fallback): SidePanel is full-bleed on phones, Descriptions collapses its columns, LogoWall drops columns, NotificationCenter fills width, wide demos scroll or wrap. The house convention is a responsive `sx` "t-shirt" object (`{ xs: '100%', sm: 380 }`). Storybook gained a **viewport toggle** (xs·375 / sm·700 / md·1024 / lg·1280 / xl·1600) mapped 1:1 to the MUI breakpoints for per-breakpoint checks. See Foundations/Breakpoints.

### Update · July 2026 — Rendering fixes

A debug sweep of all stories fixed: MUI-X standard charts collapsing to zero width in the centered canvas; AG Grid failing to register modules (error #272); the Button not forwarding refs (Tooltip/Popover anchoring); a range-Slider `aria-label` warning; and the GaugeStat `semi` variant overlapping its value with the arc.

### Update · July 2026 — Documentation accuracy pass

Audited the Getting Started, Foundations, and Guides docs against the code and corrected drift: component count, the single-typeface reality, the three-tier chart architecture, the real breakpoint/responsive behaviour, the shadow model, token paths (`vael/`), and the build tool (Vite). Team-process and product-infrastructure references were reframed as Fermie history rather than present-day fact.

### Architecture Decision Records

Active decisions for the extracted design system:

- ADR 001 — MUI v7 as the component library
- ADR 002 — 8px spacing base
- ADR 003 — IBM Plex typefaces (now consolidated to a single Mono family)
- ADR 004 — Semantic token architecture
- ADR 005 — Autocomplete over Select
- ADR 006 — AG Grid over MUI DataGrid
- ADR 007 — Font Awesome over MUI icons
- ADR 008 — Third-party library wrapper pattern; feature code never imports raw library components
- ADR 009 — WCAG 2.1 Level AA (not AAA) as the accessibility target — rationale, scope, legal context
- ADR 010 — PDF/report export accessibility: chart PNG + alt text + data-table pattern

Fermie-era ADRs that don't carry into the extracted library (a custom `SideNav` over MUI Drawer; a single `useAlert` notification API) are retained in the product's own history, not here.

### Fermie-era internal components (historical)

When this system backed the **Fermie** product, its app layer added internal components and hooks not part of the extracted library: `SearchField`, `TypographyInput`, `StatusChip`, `ListTable`/`ListTableV2`, `ModalProvider`/`useModal`/`useConfirmationDialog`, `useAlert`/`useSnackbarAlert`/`useBanner`, `BrandLogo`/`ExternalTopNav`. Vael ships the reusable primitives (`DensityProvider`, the wrapper components, the chart layer); a consuming app layers its own hooks and app-specific components on top. See Guides/Hooks.
