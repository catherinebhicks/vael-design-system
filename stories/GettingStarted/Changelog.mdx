# Changelog

Version history for the Vael Design System. V0 establishes the baseline — token system, component library, and pattern documentation — derived from the V0 Figma file.

## V0 — Initial Release · April 2026

Status: In progress — light + dark mode documented; **Blueprint / Engine-Room** visual identity.

This is the initial version of the Vael Design System documentation. It establishes the baseline token system, component library, and pattern documentation derived from the V0 Figma file.

### Update · July 2026 — Blueprint reskin

The visual identity moved to **Blueprint / Engine-Room** to match the Vael case-study landing page: **IBM Plex Sans + IBM Plex Mono** typography (replacing Inter/DM Mono), blueprint-grid surfaces, hairline borders, tightened geometry (8px buttons/inputs, 14px cards), a blue focus glow, and mono metadata labels. Charts adopt IBM Plex Mono. A single toolbar toggle now flips the Storybook chrome, components, and docs together. Brand blue `#1976d2` is unchanged.

### Architecture Decision Records (12)

- ADR 001 — MUI v7 as the component library
- ADR 002 — 8px spacing base
- ADR 003 — IBM Plex typefaces (Sans + Mono)
- ADR 004 — Semantic token architecture
- ADR 005 — Autocomplete over Select
- ADR 006 — AG Grid over MUI DataGrid
- ADR 007 — FontAwesome over MUI icons
- ADR 008 — Custom SideNav over MUI Drawer
- ADR 009 — Third-party library wrapper pattern; feature code never imports raw library components
- ADR 010 — Single notification API: `useAlert` routes by severity; `useSnackbarAlert`/`useBanner` are internal
- ADR 011 — WCAG 2.1 Level AA as the accessibility compliance target: rationale, scope, and legal context
- ADR 012 — PDF export accessibility: WCAG 2.1 AA applied to job reports, chart PNG + alt text + data table pattern
