# Overview

**Vael** is a themed design system for data-dense products — dashboards, admin tools, and internal apps. It's built on **MUI v7** with a **Highcharts** data-visualization layer, shipped as a typed React component library with this Storybook as its living documentation. Its visual identity is **Blueprint / Engine-Room** — IBM Plex Sans + Mono, blueprint-grid surfaces, hairline borders, and a brand-blue accent — precise and technical, built for screens full of data.

## What's inside

- **Foundations** — color (12 tonal ramps + semantic tokens), IBM Plex Sans / IBM Plex Mono typography, an 8px spacing scale, elevation, iconography, and motion.
- **Components** — 40+ components: MUI primitives themed to the Vael aesthetic, plus a dashboard layer (StatCard, ChartCard, Legend, TrendBadge), form components (FileUpload, InputNumber, PasswordField, AdvancedSelect), and charts (Area, Bar, Donut).
- **Patterns** — real compositions: the dashboard, empty/error states, forms, navigation shell, headings, and screen templates.
- **Guides** — installation, theming, versioning, accessibility, and contribution.

## Status

- **Version**: V0 (pre-release) — see [Versioning](?path=/docs/guides-versioning--docs)
- **Light mode**: Stable
- **Dark mode**: Stable — toggle with the sun/moon switch in the toolbar (flips the chrome, components, and docs together)
- **Accessibility**: WCAG 2.1 AA target — see the [conformance statement](?path=/docs/getting-started-accessibility--docs)
