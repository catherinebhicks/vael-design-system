# Foundations

Core visual decisions. Start here before working with components. Every component in the library is assembled from these primitives — color tokens, type scale, 8px spacing, 24 elevation levels, FontAwesome icons, and the Highcharts styled-mode chart vocabulary. Each section below links to its full page, where the tokens are rendered as live specimens.

## Color

11 semantic roles plus full tonal ramps (50–950) and deterministic chart-variable mapping. Never hardcode hex. → [Color](?path=/docs/foundations-color--docs)

## Typography

IBM Plex Sans for UI, IBM Plex Mono for labels and numeric data. A precise type scale with semibold headings. → [Typography](?path=/docs/foundations-typography--docs)

## Spacing

8px base, scale 1–8. Values beyond 64px are layout-level, not spacing. → [Spacing](?path=/docs/foundations-spacing--docs)

## Elevation

24 levels, each a three-layer shadow (umbra, penumbra, ambient). → [Elevation](?path=/docs/foundations-elevation--docs)

## Iconography

FontAwesome — Regular and Solid ship (Light with a Pro license). Never `@mui/icons-material`. → [Iconography](?path=/docs/foundations-iconography--docs)

## Data viz

Highcharts styled-mode. Deterministic variable-to-token color. Max 4 series, max 2 y-axes. → [Data Visualization](?path=/docs/foundations-data-visualization--docs)

## Motion

Functional, not decorative. Duration and easing tokens for continuity and state changes. → [Motion](?path=/docs/foundations-motion--docs)
