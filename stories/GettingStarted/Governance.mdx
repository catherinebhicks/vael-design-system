## Getting started — step by step

Quick setup paths for designers and engineers new to the system. Follow the flow for your role, then refer to the detailed guide pages linked in the sidebar.

### Designer onboarding — Figma library

1. Open Figma
2. In the Assets panel, search for **Vael Design System**
3. Enable the library for your file via **Assets → Libraries → [toggle on]**
4. Components appear in the Assets panel under their category (Inputs, Data Display, etc.)

**Figma file:** Vael Design System V0

### Using components

- Drag components from the Assets panel into your designs
- Use the properties panel to switch variants, toggle optional slots (icons, labels, etc.)
- Never detach component instances without a specific reason — detached components won't receive library updates
- Use the **Overview page** in the Figma file for a bird's-eye view of all components

### Using tokens

- Use the Variables panel to apply color tokens instead of raw hex values
- Typography tokens are pre-applied via Text Styles — apply from the text style picker
- Do not hardcode colors or font sizes directly on layers

### Design + engineering handoff

- Inspect any component in **Dev Mode** for exact token values, spacing, and export options
- Annotate handoffs with: component variant name + key props, any token overrides, interaction states, custom patterns not covered by the library

### Contribution

This is V0 — the system is actively evolving. To propose additions or changes:

1. Check the What's Not Here Yet section to see if it's already planned
2. Discuss with the design team before building net-new components
3. New components must follow the existing documentation template and be added to the Figma library before being documented here

**Note.** Do not add one-off component variations to product files without first evaluating whether they belong in the shared library.
