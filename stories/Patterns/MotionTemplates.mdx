# Motion templates

Reusable motion recipes for common surfaces — and for exported social/deck
formats (Reels 9:16, Stories 9:16, square 1:1). All durations/easings come from
the theme's `transitions`, so motion reads as one system.

## UI motion recipes

- **Enter / exit** — fade + 8px rise, `duration.enteringScreen` / `leavingScreen`,
  `easing.easeOut` in, `easing.sharp` out.
- **Expand / collapse** — height + opacity, `duration.standard`, `easing.easeInOut`.
- **Emphasis** — a single 1.02 scale pulse on success, `duration.short`.

## Export formats (for decks / social)

- **9:16 (Reels / Stories)** — one message per beat; hold each 1.5–2.5s; safe-area
  insets top/bottom for platform chrome.
- **1:1 (square)** — center-weighted; larger type; loops cleanly.

## Rules

- **Respect `prefers-reduced-motion`** — collapse to a cross-fade (see the
  `reducedMotion` token). Motion is enhancement, never the only signal.
- Animate **transform + opacity** only (compositor-friendly); avoid layout props.
- One purpose per motion — orient, confirm, or direct attention, not decorate.

## Build from

Theme `transitions` (durations + easings) · the `reducedMotion` foundation token ·
MUI transition components (`Fade`, `Grow`, `Collapse`).
