# Process controls UI

The process controls UI displays and edits live process parameters for a running experiment. Parameters group by process type into collapsible `Accordion` sections, each containing an editable `DataGrid`. The page operates in two modes — `edit` and `review` — with explicit confirmation before any change reaches hardware.

## Flow

The pattern moves through three steps: edit → review → submit.

## Structure

```jsx
<DataGrid
  stopEditingWhenCellsLoseFocus
  readOnlyEdit
  columnDefs={columnDefs}
  domLayout="autoHeight"
  getRowId={getRowId}              // keyed by run.id
  onCellEditRequest={onCellValueChanged}
  rowData={rowData}
  context={{ processType: { id, label }, serverColumns: columns }}
/>
```
