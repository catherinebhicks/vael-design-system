# Bulk inline editing

The bulk-edit pattern displays and edits many records' values inline before committing them together. Records group by category into collapsible `Accordion` sections, each containing an editable `DataGrid`. The page operates in two modes — `edit` and `review` — with explicit confirmation before any change is saved to the server.

## Flow

The pattern moves through three steps: edit → review → submit.

## Structure

```jsx
<DataGrid
  stopEditingWhenCellsLoseFocus
  readOnlyEdit
  columnDefs={columnDefs}
  domLayout="autoHeight"
  getRowId={getRowId}              // keyed by row.id
  onCellEditRequest={onCellValueChanged}
  rowData={rowData}
  context={{ category: { id, label }, serverColumns: columns }}
/>
```
