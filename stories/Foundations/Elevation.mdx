# Elevation

Elevation uses soft drop shadows to express depth and hierarchy across 25 levels (0–24). Vael keeps MUI's 25-slot elevation scale but replaces the default shadows with a **Tailwind-style** set — light, cool, low-opacity shadows tinted `rgba(16,24,40,·)` rather than pure black.

## 25 levels, soft Tailwind-style shadows

Rather than a shadow per level, the system defines **six shadow steps** (xs → 2xl) and maps them across the 25 MUI slots. Each step is one or two thin layers at low opacity (0.04–0.16). Use the lowest elevation that achieves the necessary visual separation. Elevation alone must not be the only cue for hierarchy.

**Why 25 slots?** MUI ships 25 elevation entries (0–24). Vael keeps the full scale so every component that internally references an elevation value (Dialog at 24, Card at 1) works without reconfiguration — but it substitutes its own shadow values into those slots rather than using Material's defaults.

## Shadow construction

The scale is built from **six named steps** — `xs`, `sm`, `md`, `lg`, `xl`, `2xl` — each a soft, cool-tinted shadow of one or two layers. The 25 MUI slots point at these six steps (many slots share a step), so the perceived depth grows in stages rather than 25 distinct shadows. All layers are tinted `rgba(16, 24, 40, α)` — a near-navy ink, not pure black — which keeps the shadow reading cool against the blueprint surfaces.

### The six steps

| Step | Composition | Peak opacity | Mapped to slots |
| --- | --- | --- | --- |
| xs | Single 1px layer | 0.04 | 1 |
| sm | Two layers, small offset | 0.07 | 2–3 |
| md | Two layers, medium offset/blur | 0.08 | 4–6 |
| lg | Two layers, larger offset/blur | 0.09 | 7–10 |
| xl | Two layers, wide offset/blur | 0.10 | 11–15 |
| 2xl | Single deep, wide layer | 0.16 | 16–24 |

**Why steps instead of 25 shadows?** Real elevation only needs a handful of perceptual tiers — a resting card, a floating control, a menu, a modal. Six well-tuned steps cover that range; mapping them across the 25 slots keeps MUI compatibility without hand-authoring two dozen near-identical shadows. Low opacities (0.04–0.16) and a cool navy tint keep the lift subtle rather than heavy.

## Component mappings

This table shows which elevation each component uses.

| Level | Components | Purpose |
| --- | --- | --- |
| 0 | App background, outlined variants | Flat — no shadow |
| 1 | Card (resting), Chip, Tooltip | Minimal lift — subtle surface distinction |
| 2 | Button (contained, resting) | Affordance cue for primary interaction |
| 3 | Refresh indicator, Snackbar | Transient surfaces |
| 4 | AppBar (scrolled), Bottom nav | Separation from scrolling content below |
| 6 | FAB (resting), SpeedDial | Floating affordance |
| 8 | Card (hover), Menu, Popover, SubMenu | Open / active overlay |
| 9 | Bottom sheet | Modal-adjacent surfaces |
| 12 | FAB (pressed), Date picker | Pressed / focused state |
| 16 | Drawer (side), Modal bottom sheet | Structural overlays that persist |
| 24 | Dialog | Highest — blocks all content below |

## Outlined variant

Many MUI components (Card, Paper, Button) ship an `outlined` variant that uses a 1px border instead of a shadow. Use outlined when:

- The surface is dense with other elevated elements (e.g. a card inside a dialog) and stacking shadows would look muddy.
- Print / export fidelity matters — borders render predictably, shadows may not.
- The design is already visually busy and a hairline is enough separation.

## Common pitfalls

- **Don't stack too many elevated surfaces.** If you have a Card (elevation 1) containing a Menu (elevation 8) inside a Dialog (elevation 24), the visual hierarchy becomes noise. Use outlined variants for inner layers.
- **Don't invent intermediate elevations.** Use the approved component mappings — don't pick elevation 5 arbitrarily for a custom surface. Instead ask: what is this surface's role? Map to the existing role (e.g. menu-like → 8).
- **Elevation alone is not hierarchy.** Reinforce with size, position, and opacity — users with vision impairments or in high-contrast modes may not see shadows.
