# Chart System

Charts are first-class components, not ad-hoc visualizations. The chart system is **three tiers** — a Standard tier on `@mui/x-charts` for everyday product charting, an Advanced tier on Highcharts for specialist needs, and a zero-dependency Micro tier for inline stat viz — all driven by MUI tokens and a deterministic metric-to-color map. Every series carries a distinct **line style in addition to color**, so the system holds up in colorblind, print, and screenshot contexts.

> This page is the **usage** reference (chart types, line styles, guardrails). For *how* the chart layer is built — the three tiers, the Highcharts theming mechanism, and the tradeoffs — see [Chart Layer](?path=/docs/foundations-chart-layer--docs).

## The three tiers

| Tier | Engine | Reach for it when |
| --- | --- | --- |
| **Standard** | `@mui/x-charts` (^9) | The default. Everyday product charting — line, bar, pie, scatter, gauge, radar. Lightweight, SVG, theme-native. |
| **Advanced** | Highcharts (styled mode) | Specialist needs the Standard tier can't cover — SPC / control charts, multi-axis, solid-gauge, large datasets, and export. |
| **Micro** | Zero-dependency inline SVG | Hand-rolled `Sparkline`, `WaffleChart`, and `GaugeStat` for inline stat viz inside cards and tables — no charting library at all. |

**Standard (the default).** Reach for `StandardCharts` first — the MUI-X community charts, re-exported under the `StandardCharts` namespace, themed by the same tokens as the rest of the system and following the light/dark toggle automatically. `@mui/x-charts` is a direct dependency, so nothing extra to install.

**Advanced (Highcharts).** `HighchartsChart` and its wrappers (`AreaChart` / `BarChart` / `DonutChart` / `ControlChart` / `MultiAxisChart` / `GaugeChart` / `RadarChart` / `SparklineChart`) render with **[Highcharts](https://www.highcharts.com/)** via `highcharts-react-official`, themed to the Blueprint aesthetic through a global `Highcharts.setOptions` plus a per-render `buildVcThemeOptions(theme)` merge in `vcDefaults.ts`. `highcharts` and `highcharts-react-official` are **optional peer dependencies** — install them only if you use the Advanced tier:

```bash
npm install highcharts highcharts-react-official
```

> **Licensing.** Highcharts is free for non-commercial use but requires a **commercial license** for commercial products. Because it's a peer dependency, that licensing relationship is between the consuming application and Highcharts — the design system does not bundle or relicense it. See the [Highcharts license](https://shop.highcharts.com/).

**Micro.** `Sparkline`, `WaffleChart`, and `GaugeStat` are drawn as plain SVG with no charting engine behind them — small enough to sit inline in a `StatCard`, a table cell, or a dashboard tile without pulling in a library.

## Chart patterns

- **Default** — One metric: actual vs threshold, with deadband and events.
- **Exploratory** — Two y-axes maximum, secondary de-emphasized to 72% opacity.
- **Diagnostic** — Opt-in deviation fill and dense event markers; gated by flag.

## Chart types — when to use which

- **Line** — Continuous metric over time. This is the default.
- **Step** — Discrete state changes: mode, phase, threshold moves.
- **Bar** — Compare a scalar across categories: jobs, servers.
- **Stacked area** — Part-to-whole composition over time: request mix, traffic split.
- **Box plot** — Job-to-job variability; outlier identification.
- **Scatter** — Relationship between two measurements: correlation.

## Series line styles

| Variant | Style | Use for |
| --- | --- | --- |
| Actual | 2px solid | Measured value |
| Threshold | 2px dashed | Target / control value |
| Predicted | 1px dotted | Forecasted value |
| Muted | 40% opacity | Backgrounded series |
| Selected | 3px stroke | User-focused series |

## Guardrails enforced in code

- No rainbow palettes or arbitrary color.
- No more than **4 visible series** by default.
- No more than **2 y-axes**.
- No opaque deadbands (8–12% fill only).
- No drop shadows inside the plot area.
- No default Highcharts theme — styled mode only.
- No inline hardcoded colors or styles.
- No interpolation across gaps — gaps must be visible.

**Why 4 series / 2 axes?** Pre-attentive visual processing reliably tracks about 4 distinct colored elements without counting. A third y-axis has no natural placement and typically floats inside the plot area, creating ambiguity about which axis governs which series.
