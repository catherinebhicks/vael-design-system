# Vael case study

Vael is a self-directed public design-system project by Catherine Hicks. This case study focuses on the decisions behind the system: how an earlier production design-system experience informed the public rebuild, how design and code were brought into one working loop, and how accessibility, governance, documentation, and system craft were treated as product-design problems.

## What the case study covers

The narrative examines the design ↔ code loop, semantic tokens, accessibility and verification, governance, component maturity, documentation, and the decisions required to keep a design system coherent as it grows.

Four focused essays go deeper on specific parts of the work:

Supporting diagrams live in `narrative/visuals/`. The `landing/` directory contains the copy, design, and specification work for presenting the case study as a standalone web experience.

## Project boundary

Vael is intentionally public and self-directed. The earlier production context that informed part of the work remains anonymized; proprietary employer/client design-system work is not represented here as if it were part of Vael.
