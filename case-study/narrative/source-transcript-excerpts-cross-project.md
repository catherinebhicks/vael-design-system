# Source: real transcript excerpts — beyond Vael, across the practice

**What this is.** Companion to `source-transcript-excerpts.md` (which covers the Vael build). These verbatim quotes come from the actual Claude Code session logs of my *other* projects — the design agency, the portfolio, teaching materials, task/system reconciliation, client work, job-search, side builds. They're the evidence for the case study's third movement: **it stopped being how I built one design system with AI and became how I run a whole practice.** Same pattern everywhere — AI collapses production; taste, judgment, ownership, and course-correction are the job.

**Provenance & anonymization.** Verbatim, typos preserved. Pulled from ~20 sessions across projects (Mar–Jul 2026). Session IDs are the first 8 chars of the log filename. Names of the agency, clients, students, a former employer, and a nonprofit have been **kept out of the quotes in the main sections** (or generalized in the context lines to "the studio," "a client," "a former employer"). A few quotes that are genuinely valuable *but* carry sensitive provenance are quarantined at the bottom under **⚠️ Sensitive — scrub before any public use**, kept verbatim with a scrub note so the raw material isn't lost. Re-check anything before it goes public.
